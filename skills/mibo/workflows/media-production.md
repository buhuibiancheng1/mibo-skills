# 媒体与文件制作

根据[完整功能目录](../references/catalog.md)选择实际任务：图片、音乐、视频生成；配音与声音克隆；降噪、音频剪辑、卡点、长片切片、绿幕、图像处理、抠图；字幕与翻译；图文卡片、图表、海报、排版、PDF、思维导图；动画、微短剧及原片成片。

图像、视频及参考图编辑先遵循总控 Skill 的“图像与视频生成方式”：优先真实可用的宿主原生工具，生成前询问用户；本次明确选用 Mibo 后才进入以下 Mibo 调用流程。不得因原生不可用或失败而自动切换到 Mibo。

用户无需填写技术编号。用户选择 Mibo 的普通 AI 生图对应 27「AI 生图」`ai-image-gen`，直接用 `mibo_get_skill` 获取该项参数，无需先搜索目录。其他未知用途才使用 `mibo_search_skills` 定位，`mibo_get_skill` 获取本项公开参数，`mibo_run_skill` 提交本次要求；图像/视频生成须在 request 顶层携带用户本次选择 `generation_choice="mibo"`；使用真实当前项目和素材标识，复用用户已提供的文件，不搜索本机 Mibo 安装目录。输入缺项只询问阻碍执行的必要素材或要求；一般风格、配色可按用户描述选择合理默认值，不额外设置问卷。工具未加载时执行总控 Skill 的工具发现流程，不自动改用其他服务。

收到需要 Agent 创作或编排的回执时，完成实际内容后继续使用已开放的制作工具。媒体操作用 `mibo_media_operations` 获取支持范围，再调用 `mibo_process_media`；图文与文档使用 `mibo_render_document`。不能把脚本、分镜、制作说明或返回操作参数称为已经生成文件。服务不支持的部分明确说明，不虚构成品。

声音任务使用用户获授权的素材和本项目真实音色；`mibo_list_voices` 查询可用音色，不能编造。字幕与章节复用 Mibo 已有转写及真实时间；需要新转写时调用 Mibo 服务，不能根据文字均分或猜测时间。

Mibo 视频生成包括组合任务中选用 Mibo 的每次生成：先展示本次服务端预计积分、提示词、具体规格与参考素材，再等待用户本人在当前对话明确同意；只有之后才能授权原报价。改参数或素材重新报价确认。多镜头任务不能用一次笼统授权代替尚未展示的后续报价。

保留原素材，遵守服务与当前宿主的素材权限、内容许可及安全限制。结果未知查询原任务，不重复生成。取得真实图片、音视频或文件后在当前对话交付预览、附件或本次只读链接。实际未完成的部分逐项说明，不能把部分成功当作整单完成。
